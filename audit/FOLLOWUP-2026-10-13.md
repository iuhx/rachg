# 功能复查与优化记录

日期：2026-10-13。基线：`a959afd`。本轮检查覆盖当前所有可见栏目及相关
文件、笔记、邮件接口，重点验证故障、重复操作、请求乱序和跨栏目状态。

## 本轮修复

| 功能 | 问题与处理 |
| --- | --- |
| 邮件草稿 | 原先切换栏目或关闭后重新 Compose 会清空草稿。现在首次打开后保持编辑组件，关闭/切换只隐藏；丢弃需明确确认，离开页面前提醒。成功发送后清空草稿。 |
| 发信 | 增加即时提交锁，避免 React 更新按钮状态前重复发送。发送中锁定收件人、主题和正文，失败保留输入且不自动重发。新回复不会覆盖已有草稿。 |
| 邮件刷新/删除 | 收件和已发列表只接受最新刷新；删除使先前刷新失效；已失效的详情响应不能复活删除/移除的邮件。删除 A 时不会取消正在加载的 B。 |
| 笔记保存/删除 | 切换笔记等待已经在途的保存完成，无需再次点击；删除等待保存结束，使用确认时的笔记 ID，防止确认对象随当前选中项变化。重复确认只删除一次。 |
| 文件上传 | 失败保留 File 对象和原有效期，可直接重试。超限和多文件投放给出明确提示。即时提交锁避免重复上传；全局上传指示保持到所有并发上传结束。 |
| 新建弹窗 | 空标题/未选文件不再关闭弹窗或显示成功；即时提交锁阻止重复创建。 |
| 快捷键 | 编辑/确认弹窗内不会通过 Ctrl/Cmd+K 再叠加命令面板；笔记快捷键不再截获其他弹窗和文本框中的输入。 |
| 登录状态 | 未登录时明确提示私有数据需登录，不再让文件和笔记列表永久停留在 Loading。浏览器本地工具仍可使用。 |
| 设置 | 移除固定 Active 标记，初始显示 Not checked；验证真实 JSON 健康响应才显示 API reachable。登录 HTML、拒绝响应、异常和超时都显示失败。 |
| 文件有效期 | 改为完整匹配小时/天数，修复 21 hours、101 hours 等被子串匹配误识别为 1 hour 的错误。仍保留永久与 1–168 小时范围。 |

- 本轮不声称已经证明所有场景无 bug。浏览器验证未登录生产账户；真实线上
  Access 配置、压力测试和备份恢复演练仍未完成。测试没有发送真实邮件、上传
  生产文件、修改 DNS 或部署云端代码。

  的重叠保存。邮件完整的客户端操作 ID/服务商幂等尚未实现，丢失发送响应后
  手工重发仍需先核对服务商结果。

  配置仍是之前审计的待办。Projects 新建继续停用，避免未持久化数据丢失。
